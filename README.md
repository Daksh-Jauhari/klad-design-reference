# KLAD design reference

A saved copy (via saveweb2zip) of the KLAD Syndicate website, klad.design. It's kept here only as a visual and layout reference for the RefillGuard project.

**Not affiliated with KLAD Syndicate.** All text, images, logos, team photos and the Helvetica Now Display font in this repo belong to their respective owners. Nothing here is an original work of this repo's owner.

## Contents

- `index.html`: the saved page
- `css/`, `js/`: compiled styles and scripts
- `images/`, `fonts/`: page assets

To view it, open `index.html` in a browser.
